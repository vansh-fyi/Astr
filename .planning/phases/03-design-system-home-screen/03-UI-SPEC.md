## State Contract

### Loading State

- `globalLoadingProvider == true` → `CosmicLoader` overlay covers full screen at `Color(0x80000000)` (preserve existing behavior)
- Individual `AsyncValue` states from `weatherProvider`, `astronomyProvider`, `conditionQualityProvider`, `visibilityProvider`
- While loading: home screen renders with placeholder values (not a skeleton, not a blank screen):
  - Hero condition label: "--"
  - Sky state subtitle: "Loading sky conditions..."
  - Zone badge: "Zone --"
  - Cloud cover bar: 0% fill
  - Sun/moon times: "--:--"
  - Visibility: "-- Sky"
  - Moon illumination: "--%"
- Background image: defaults to `assets/img/starry_sky.jpg` until sky state resolves

### Error State

- Show `showGlassToast(context, 'Sky data unavailable. Check your connection.')` — no full-screen error page
- Home screen continues showing last valid state or loading placeholders
- No red error background — dark starfield aesthetic maintained in all states

### Data State

- Background image: `SkyStateBackground` renders correct JPG for resolved sky state
- All cards populate with live data from providers
- Sky state → background mapping is a pure switch (no animation between states in Phase 3; static swap)

### Navigation State

- **Active nav tab label**: `AppColors.textPrimary` (#F4F5F5) + blue glow text shadows — verbatim from Figma node 119:92:
  ```dart
  shadows: [
    Shadow(color: Color(0xFF3A7FFF), blurRadius: 12.2, offset: Offset(0, 1)),
    Shadow(color: Color(0x40FFFFFF), blurRadius: 1, offset: Offset.zero),
  ]
  ```
- **Inactive nav tab label**: `AppColors.textSubdued` (#7D8792), no shadow
- Nav bar tab groups (Figma node 119:92): Home+Objects at `left=20, top=9, gap=32`; Forecast+Settings at `left=237, top=9, gap=32`
- No loading indicator per tab — global `CosmicLoader` handles loading

## Home Screen Layout Order (Top to Bottom)

Layout is a single `Stack` with a scrollable `Column` body below the pinned glass header.

1. **SkyStateBackground** — `Positioned.fill`, z-index 0, behind all content
2. **Glass header** — `Positioned(top: 0)` in `ScaffoldWithNavBar` — pinned, always on top
3. **Hero section** — `Column(children: [HeroConditionLabel, ZoneBadge])` — vertically centered in upper 55% of screen height
4. **ConditionsCard** — below hero section, horizontally padded to screen edge — `kConditionsCardWidth` = 345px
5. **Mini-cards row** — `Row(children: [VisibilityMiniCard, MoonMiniCard])`, equal-width halves, below conditions card
6. **HighlightsFeed** — `ListView` of top 3 objects, below mini-cards, above nav bar
7. **Nav bar** — `ScaffoldWithNavBar` bottom navigation (already implemented)

All content (3–6) lives inside a `SingleChildScrollView` with `padding: EdgeInsets.only(top: AppSpacing.kHeaderContentOffset, bottom: navBarHeight + bottomInset)`.

## Token Enforcement Rule (DS-02)

Every active file in `lib/` that references a hardcoded color, font size, or spacing value must be migrated to a token in Phase 3. This applies to all 15 surfaces, not only the home screen.

Migration checklist (scan these patterns):
- `Colors.blueAccent` → `AppColors.accent`
- `Colors.white` / `Colors.white.withOpacity(x)` → `AppColors.textPrimary` or `AppColors.textPrimary.withOpacity(x)`
- `Color(0xFFxxxxxx)` inline → appropriate token
- `AppTheme.deepCosmos` → `AppColors.surface`
- `AppTheme.oledBlack` → `AppColors.surface`
- `AppTheme.starlight` → `AppColors.textPrimary`
- `AppTheme.accentPurple` → no direct replacement in Phase 3 (purple is removed from design system; replace any usage with contextually appropriate token)
- `AppTheme.accentCyan` → `AppColors.accentSecondary`
- `fontSize: x` inline → `AppTypography.*` style
- `SizedBox(height: x)` / `EdgeInsets.all(x)` with non-token literal → `AppSpacing.x`
