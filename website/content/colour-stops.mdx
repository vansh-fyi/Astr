<DocSection id="naming" title="Naming">

Every stop is a theme variable named `--color-{palette}-{step}`. Steps run from 50 (lightest) to 950 (darkest) in eleven increments: 50, 100, 200, 300, 400, 500, 600, 700, 800, 900, 950.

Tailwind exposes each stop as a utility, for example `bg-space-grey-100` or `text-aurora-green-400`.

<DocNote>The stops are absolute. A stop is never lightened, darkened or tinted. To make a colour fainter, use a step of the opacity ladder.</DocNote>

</DocSection>
